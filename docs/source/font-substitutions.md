# Authorized font alternatives

Triyan explicitly authorized internet sourcing or similar alternatives on 11 November 2026.

- Segoe UI → Selawik, supplied by Microsoft as an open-source Segoe UI replacement: https://github.com/microsoft/Selawik . Release 1.01 binaries and OFL license are saved locally. Microsoft notes missing Segoe kerning and hinting differences; exact typography parity is not claimed.
- Gilroy headings across the four home pages → local Urbanist 700, a geometric sans-serif alternative already used in the design body. Original Gilroy text also appears in home hero/match headings; this substitution is explicit and is not exact typography parity.
- Gilroy Bold → Manrope 700 for the dark dashboard VS label (8438:9838), a geometric sans-serif alternative selected for the compact uppercase label. Official Google Fonts distribution: https://github.com/google/fonts/tree/main/ofl/manrope . OFL license is local. This is a visual alternative, not a metrically identical Gilroy replacement.

All other supplied font families retain their original local official files. Downloads and SHA-256 checksums are recorded in font-manifest.json. No remote runtime font requests.
